# UIZZE reference policy

Start with the brief, existing components, and local design system. A capable agent does not need a reference for every UI decision.

Search UIZZE only when one concrete layout, state, pattern, or interaction question remains unresolved and visible evidence could change the implementation. Refine the query at most once.

Use no more than two perceptually distinct references. Inspect at most one preview by default. Request deeper detail only when the selected reference has already proved relevant.

If confidence is low, retrieval has a material gap, the image is unavailable, or the result does not match the platform and task, abstain. Continue with local evidence and judgment. Do not mention UIZZE, add filler advice, or search again after an abstention.

Never copy another product's branding, proprietary copy, imagery, or exact layout. Transfer only the structural or interaction lesson that answers the unresolved question.
